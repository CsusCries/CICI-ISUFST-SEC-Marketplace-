# CICI - ISUFST-SEC Market Place

A single-page marketplace site built as a group project.

## Open the site

No install needed. Open `index.html` in any browser.

## Project layout

```
.
├── index.html          # The site markup
├── css/styles.css      # All styles
├── js/script.js        # All JavaScript
├── docs/               # Report notes, screenshots, and drafts
├── .claude/skills/     # Custom Claude Code skills for this project
└── README.md
```

## Claude skills

The skills in `.claude/skills/` help with UI work, bug review, docs, Git, and planning. They load automatically in Claude Code sessions opened on this repo.

## Known limitations

- The site is one file, so changes to styles or scripts affect the whole page.
